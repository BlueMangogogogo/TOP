# 浩泉-每日智能复盘

## 依赖

本 Skill 依赖：
- `浩泉-报告排版引擎`（`skills/浩泉-报告排版引擎/`）— Markdown → HTML 报告渲染
- `tdx-board-radar` 技能（`~/.openclaw-tdxclaw/.openclaw/skills/tdx-board-radar/`）— 板块资金雷达数据
- 通达信数据工具（`tdx_quotes`、`tdx_kline`、`tdx_screener`、`tdx_api_data` 等）
- 问达资讯工具（`wenda_news_query`、`wenda_notice_query`、`wenda_report_query`）
- web_search（外盘、宏观数据补充）

## 报告类型与触发时间

| 报告类型 | 触发时间 | 适用日 | 核心目标 |
|---------|---------|--------|---------|
| **早盘扫描** | 8:00 AM | 开盘日 | 外盘收盘+盘前消息+今日关注方向 |
| **午盘扫描** | 11:40 AM | 开盘日 | 上午行情总结+板块轮动+下午展望 |
| **深度复盘** | 23:00 PM | 开盘日 | 全天深度分析+明日推演+策略建议 |
| **周度盘前** | 23:00 PM | 开盘前夜（通常周日） | 假期消息汇总+本周策略研判+外盘累计走势 |

**交易日判断：** 周一至周五（排除中国法定节假日），通过 `tdx_kline` 抽查上证指数今日日线是否有数据来验证。

## 全局设计原则

### 散户复盘视角
聚焦：板块热点与趋势、资金流向与技术量价、热点新闻/政策/事件/公告催化、市场情绪、潜在机会还是风险。基本面也当成事件/消息来理解，不追求深度财务分析。

### 概念区分原则（严格执行）
**以下概念有完全不同的驱动逻辑，分析时不可混为一谈：**

| 方向 | 核心驱动 | 映射标的 |
|------|---------|---------|
| AI算力/服务器/光通信 | 英伟达股价、CSP资本开支、订单 | NVDA、Google、Meta |
| 半导体设计 | AMD/Intel映射、下游需求景气 | AMD、INTC |
| 半导体设备/制造 | 国产替代、扩产周期 | — |
| 存储芯片 | 涨价预期、美光/闪迪映射 | MU、WDC |
| AIDC/算力租赁 | 算力需求、租金趋势 | — |
| AI应用/软件 | AI商业化进程、产品落地 | OpenAI、Anthropic |
| 国产替代 | 政策驱动、自主可控 | — |

### 输出规范
- ✅ 必须包含的内容严格包含，❌ 不得包含的内容绝不写入，⚠️ 条件性内容按条件判断
- **绝对不写入报告**：复盘框架优化建议、验证方法、交叉验证说明、数据来源标注、公式推导、内部备注
- 免责声明仅保留指定格式

## 执行流程总览

### 通用 Step 0 — 环境检查

1. 确认当前是否为交易日（通过 `tdx_kline` 抽查上证指数今日日线）
2. 确认当前时间对应哪个报告类型
3. 读取上一期同类型报告（`分析报告汇总/YYYY-MM-DD/`），引用上期关键判断做对比
4. 检查对应报告是否已生成，若已存在且非手动触发则跳过
5. 获取 onechart.top 最新数据（`web_fetch` url=`https://onechart.top/radar_data_latest.js`）
6. 读取板块资金雷达趋势数据（`D:\库\Desktop\TdxClaw金融龙虾\板块资金雷达\output\board-radar.html` 最近3天数据）

## 三、深度复盘（23:00 PM）⭐️ 核心

### 设计原则
- **深度**：因果分析，不浮现表面
- **多维度**：技术面+资金面+情绪面+消息面
- **前瞻性**：不只总结今天，必须推演明天
- **散户视角**：板块热点/趋势 + 资金流向/量价 + 新闻催化 + 市场情绪 + 机会/风险
- **概念区分**：严格执行概念区分原则，不同逻辑分开写
- **数据驱动**：每个判断有数据支撑，但不在报告中展示验证过程

## 🔌 板块资金雷达数据提取与趋势分析

> 核心数据来自本地板块资金雷达系统（每日22:00自动更新）。onechart.top `radar_data_latest.js`（交易日 17:00-17:30 同步）作为加权评分辅助参考。

### 数据源
本地板块资金雷达每日自动计算（交易日 22:00 更新）。onechart.top `radar_data_latest.js`（交易日 17:00-17:30 同步）作为加权评分辅助参考。

### 提取关键字段
| 字段 | 含义 | 用途 |
|------|------|------|
| `index_name` | 板块名称 | 识别板块 |
| `pct_change` | 涨跌幅 | 判断当日表现 |
| `Swing_Ratio_Val` | 波段流入率（×100=%） | 30日趋势判断 |
| `Ratio_Raw_Pct` | 单日流入率（×100=%） | 当日资金态度 |
| `Amount_Raw_BN` | 单日净额（亿元） | 资金规模判断 |
| `Swing_RankPos` | 波段排名 | 排名变化 |
| `Ratio_RankPos` | 单日排名 | 排名变化 |
| `Amount_RankPos` | 净额排名 | 排名变化 |
| `Swing_Top30d` | 近30天在榜天数 | 持续性判断 |
| `Ratio_Top30d` | 近30天单日在榜天数 | 持续性判断 |
| `Swing_Score` | 加权评分 | 综合排名 |

### 趋势分析规则

#### 机构建仓信号（需同时满足）
1. 连续3-5天在榜（Swing_Top30d ≥ 3）
2. 波段流入率/单日流入率/单日净额/排名变化"大部分"在逐步上升
3. 对应板块股价未明显大涨（涨幅 < 10%）
⇒ 提示"🟢 关注建仓：[板块名]"

#### 短线退潮信号（满足任一即触发）
1. 在榜天数 > 7天 + 今日单日流入率转负 + 排名下降 ≥ 5位
2. 此前连续在资金进攻榜，但最近连续3天以上流出或下跌
⇒ 提示"🔴 建议撤退：[板块名]"

#### 排名飙升信号
- 今日排名较昨日上升 ≥ 10位
⇒ 提示"📈 排名飙升：[板块名]，关注后续持续性"

## Cron 定时任务配置

本 Skill 配置 3 个 Cron 定时任务（覆盖 4 个报告类型）：

### 1. 早盘扫描（交易日 8:00）
```
schedule: "0 8 * * 1-5" (Asia/Shanghai)
```
→ payload 中先判断是否为交易日，是则执行早盘扫描，否则跳过。

### 2. 午盘扫描（交易日 11:40）
```
schedule: "40 11 * * 1-5" (Asia/Shanghai)
```
→ payload 中先判断是否为交易日，是则执行午盘扫描，否则跳过。

### 3. 深度复盘/周度盘前（每日 23:00）
```
schedule: "0 23 * * *" (Asia/Shanghai)
```
→ payload 中判断：
- 如果是交易日（周一至周五·非节假日）→ 生成深度复盘
- 如果是开盘前夜（周日或节前最后休息日）→ 生成周度盘前
- 其他情况跳过
