# 浩泉-报告排版引擎 — Markdown → 排版 HTML 报告

## 何时使用

- 用户要求"输出 PDF"、"生成报告"、"导出分析"
- 任何需要正式排版输出的分析结果
- **默认报告输出方式**，除非用户指定其他格式

## 文件结构

```
skills/report-builder/
├── SKILL.md          ← 本文件
├── report.css        ← 排版样式（红·黄·灰·黑）
└── md2html.py        ← Markdown → HTML 转换脚本
```

## 输出目录

```
分析报告汇总/
├── 2026-05-06/
│   ├── 房地产开发板块资金流向分析.html
│   └── 房地产开发板块资金流向分析.pdf   ← 用户手动 Ctrl+P 导出
├── 2026-05-07/
│   └── ...
```

- 自动创建日期子文件夹（`YYYY-MM-DD`）
- 文件名 = 文章 `# 标题`（自动安全处理）

## 使用流程

### Step 1：AI 写 Markdown

写一个 `.md` 文件，遵守以下约定：

```markdown
# 文章标题（必须：作为 h1，自动提取为文件名）

日期: 2026年5月6日 22:54      ← 可选：显示在标题下方

## 二级标题                      ← 左侧黄线装饰

正文内容 **加粗** 普通文字。

| 表头1 | 表头2 |                  ← 黄底表头 + 斑马纹
|------|------|
| 数据  | 数据  |

> ⚠ 警告内容                   ← 红色警告框
> 💡 提示内容                   ← 黄色高亮框

### 三级标题                     ← 无左线，深灰
```

### Step 2：运行转换

```bash
python skills/report-builder/md2html.py 临时文件.md
```

输出自动写入：`分析报告汇总/YYYY-MM-DD/文章标题.html`

### Step 3：用户导出 PDF（手动）

- 浏览器打开 HTML → Ctrl+P → 另存为 PDF
- 或 AI 使用 `browser` 工具渲染

## 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 品牌黄 | `#ebb543` | 表头、h2 左线、高亮框边框 |
| 黄浅底 | `#f7e8c5` | 高亮框背景、表格悬停 |
| 警告红 | `#c0392b` | 警告框左线、文字 |
| 红浅底 | `#fdf0ef` | 警告框背景 |
| 正文黑 | `#1a1a1a` | 标题、加粗 |
| 正文灰 | `#2c2c2c` | 段落文字 |
| 辅助灰 | `#888` / `#bbb` / `#f0f0f0` | 元信息、边框、斑马纹 |

## 字体

- 首选：微软雅黑 → PingFang SC → Noto Sans SC → system-ui
- 已确认 Windows 环境下无空心方块问题

## 设计原则

- **简洁**：无封面、无目录，标题+日期直接进入正文
- **一目了然**：表格黄头、h2 左线、警告/高亮框清晰分区
- **响应式**：手机端自动缩小字号和间距
- **底部必有免责声明**
